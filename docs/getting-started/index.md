## 페이지 구성

모든 기술 페이지는 다음 순서로 구성됩니다.

!!! spec "스펙 · 릴리즈"
    관련 TS 번호와 절, 기능이 도입된 릴리즈

!!! basic "한눈에 보기"
    <span class="lv lv1">기초</span> 개념과 비유. 수식 없이 "무엇이고 왜 필요한가"만 설명합니다.

**본문** <span class="lv lv2">중급</span> 구조, 파라미터, 표, 그림, 동작 순서

??? expert "전문가 노트"
    <span class="lv lv3">전문가</span> 스펙 수식, 경계 조건, 릴리즈별 차이, 실무에서 자주 헷갈리는 점.
    기본으로 접혀 있으니 필요할 때 펼쳐 보세요.

마지막에는 **LTE ↔ NR 비교**(해당하는 경우)와 **관련 페이지** 링크가 붙습니다.
