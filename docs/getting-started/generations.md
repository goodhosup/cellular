# 이동통신 세대의 진화

!!! spec "참고 문서"
    ITU-R M.1457 (IMT-2000), M.2012 (IMT-Advanced), M.2083 (IMT-2020 비전), M.2160 (IMT-2030 프레임워크)

!!! basic "한눈에 보기"
    이동통신 "세대(G)"는 약 10년마다 바뀌었습니다. 세대가 바뀔 때마다 **무엇을 실어 나르느냐**가 달라졌습니다.

    - 1G: 목소리를 아날로그 신호 그대로
    - 2G: 목소리를 디지털로 (+ 문자)
    - 3G: 데이터 (+ 영상통화, 모바일 인터넷)
    - 4G: 모든 것을 IP 패킷으로 (음성도 데이터처럼)
    - 5G: 사람 + 사물 + 산업 (초고속, 초저지연, 초연결)
    - 6G: 통신 + 센싱 + AI (네트워크가 "보고 판단하는" 단계)

## 세대별 비교 { .l2 }

| 세대 | 시기 | 대표 기술 | 다중 접속 | 핵심망 | 최고 속도(이론) | 주요 서비스 |
|---|---|---|---|---|---|---|
| 1G | 1980s | AMPS, NMT | FDMA | 회선 교환 | — (아날로그) | 음성 |
| 2G | 1990s | GSM, IS-95(cdmaOne) | TDMA / CDMA | 회선 교환 (+GPRS 패킷) | 수십~수백 kbps (EDGE) | 디지털 음성, SMS |
| 3G | 2000s | WCDMA/HSPA, CDMA2000/EV-DO | CDMA | 회선 + 패킷 | 수십 Mbps (HSPA+) | 모바일 인터넷, 영상통화 |
| 4G | 2010s | **LTE**, LTE-Advanced (Pro) | **OFDMA** / SC-FDMA | **All-IP (EPC)** | 1 Gbps 이상 (LTE-A) | 모바일 브로드밴드, VoLTE |
| 5G | 2019~ | **NR** | OFDMA (유연한 numerology) | **서비스 기반 (5GC)** | 20 Gbps (IMT-2020 목표) | eMBB, URLLC, mMTC |
| 6G | 2030~ (예정) | 미정 (3GPP Rel-21~) | 미정 | AI-native (논의 중) | 수십~수백 Gbps (논의 중) | 몰입형 통신, ISAC, AI |

## 무엇이 계속 바뀌었나 { .l2 }

**1. 다중 접속 방식** — 여러 사용자가 같은 주파수를 나눠 쓰는 방법이 FDMA → TDMA → CDMA → OFDMA로 바뀌었습니다.
대역폭이 넓어질수록 다중 경로 페이딩에 강한 OFDM이 유리해져서, 4G 이후로는 OFDM 계열이 표준이 되었습니다.
([OFDM 원리](../basics/ofdm.md) 참고)

**2. 핵심망 구조** — 2G/3G는 음성용 회선 교환망과 데이터용 패킷망을 따로 두었습니다.
4G의 EPC는 회선 교환을 없애고 모든 트래픽을 IP로 처리합니다. 그래서 음성은 IMS 위의 VoLTE가 되었습니다.
5G의 5GC는 기능을 서비스 단위(NF)로 쪼개고 HTTP 기반 인터페이스(SBA)로 연결합니다.

**3. 주파수** — 세대가 올라갈수록 더 높은 주파수와 더 넓은 대역을 씁니다.
LTE 캐리어 하나는 최대 20 MHz, NR은 FR1에서 100 MHz, FR2(mmWave)에서 400 MHz까지 씁니다.
6G에서는 7–24 GHz 대역(FR3)과 sub-THz가 논의되고 있습니다.

**4. 설계 목표** — 4G까지는 "더 빠르게"가 주목표였습니다.
5G부터는 속도(eMBB)와 함께 지연·신뢰성(URLLC), 연결 밀도(mMTC)를 동시에 목표로 잡았습니다.

## IMT 요구사항 비교 { .l2 }

ITU-R가 정한 "이 정도면 그 세대로 인정한다"는 최소 기준입니다.

| 항목 | IMT-Advanced (4G) | IMT-2020 (5G) |
|---|---|---|
| 최고 전송 속도 (DL) | 1 Gbps (저이동성) | 20 Gbps |
| 사용자 체감 속도 | — | 100 Mbps |
| 사용자 평면 지연 | 10 ms | 1 ms (URLLC) / 4 ms (eMBB) |
| 연결 밀도 | — | 10⁶ 기기/km² |
| 이동성 | 350 km/h | 500 km/h |
| 최고 스펙트럼 효율 (DL) | 15 bit/s/Hz | 30 bit/s/Hz |

??? expert "전문가 노트 — 'LTE는 4G인가?'"
    엄밀하게는 **Rel-8/9 LTE는 IMT-Advanced 요구사항을 충족하지 못했습니다**.
    IMT-Advanced 요구사항을 만족하도록 제출된 것은 **Rel-10 LTE-Advanced**입니다.
    ITU는 2010년 말 마케팅 용어로서 LTE·WiMAX·HSPA+를 "4G"로 부르는 것을 사실상 허용했고, 그 뒤로 Rel-8 LTE도 4G로 부르게 되었습니다.

    같은 일이 5G에서도 있었습니다. **Rel-15 NR**이 IMT-2020의 첫 제출이고,
    Rel-16까지 포함한 "3GPP 5G" 패키지가 2020년 ITU-R에서 IMT-2020으로 승인되었습니다.
    URLLC 요구사항(1 ms, 99.999%)은 Rel-16에서 본격적으로 충족됩니다.
