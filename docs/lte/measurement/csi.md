# CQI · PMI · RI

!!! spec "스펙 · 릴리즈"
    CSI 보고 절차: TS 36.213 §7.2 (비주기 §7.2.1, 주기 §7.2.2, CQI 정의 §7.2.3, PMI §7.2.4) · CQI 표: Table 7.2.3-1 (64QAM), 7.2.3-2 (256QAM, Rel-12), 7.2.3-4 (1024QAM, Rel-15)

    Rel-8~ (Rel-10 CSI-RS 기반 CSI, Rel-11 CSI 프로세스, Rel-13 CRI·FD-MIMO)

!!! basic "한눈에 보기"
    기지국은 단말이 보고하는 **CSI(Channel State Information)**를 보고 "이 단말에게 몇 레이어로, 어떤 MCS로 보낼까"를 정합니다.

    - **CQI (Channel Quality Indicator)**: "이 정도 속도(변조+코딩률)면 오류율 10% 이하로 받을 수 있어요" (0–15)
    - **PMI (Precoding Matrix Indicator)**: "이 프리코딩 행렬로 보내 주면 좋겠어요"
    - **RI (Rank Indicator)**: "레이어 몇 개까지 받을 수 있어요"

    CQI는 단순한 신호 세기가 아니라 **단말 수신기 성능까지 반영한 추천값**입니다.

## CQI 정의 { .l2 }

> 단말은 CSI 기준 자원에서 **전송 블록 오류 확률이 0.1을 넘지 않는** 가장 높은 CQI 인덱스를 보고한다. (TS 36.213 §7.2.3 요지)

## 보고 방식 { .l2 }

| 구분 | 채널 | 트리거 | 내용 |
|---|---|---|---|
| **주기 (periodic)** | PUCCH format 2/2a/2b (또는 3) | RRC `cqi-pmi-ConfigIndex` (2–160 ms) | 광대역 CQI/PMI, RI, 부대역 CQI(순환) |
| **비주기 (aperiodic)** | PUSCH | DCI 0/4의 **CSI request** 필드 (또는 RAR) | 상세 부대역 CQI/PMI, 한 번에 많은 정보 |

### 보고 모드 (PUSCH 비주기)

| 모드 | CQI | PMI | 쓰임 |
|---|---|---|---|
| 1-2 | 광대역 | 부대역별 | TM4 |
| 2-0 | 단말 선택 M개 부대역 + 광대역 | 없음 | TM1–3 |
| 2-2 | 단말 선택 M개 부대역 | 선택 부대역 PMI + 광대역 PMI | TM4 |
| **3-0** | 망 설정 부대역 전체 (차분 2비트) | 없음 | TM1–3, TM7 |
| **3-1** | 망 설정 부대역 전체 | 광대역 PMI | TM4, TM9 |
| 3-2 (Rel-12) | 망 설정 부대역 | 부대역 PMI | TM4, TM9 |

PUCCH 주기 보고 모드는 1-0, 1-1, 2-0, 2-1입니다(첫 숫자: 1 광대역 / 2 단말 선택 부대역, 둘째: 0 PMI 없음 / 1 단일 PMI).

??? expert "전문가 노트 — CSI 기준 자원과 실무 해석"
    **CSI 기준 자원(reference resource).** 단말은 CQI를 계산할 때 "가상의 PDSCH"를 가정합니다.
    - 시간: 보고 서브프레임 \(n\)보다 \(n_{CQI\_ref}\)(FDD 최소 4) 이전의 유효 DL 서브프레임
    - 첫 **3 심볼은 제어 영역**, PSS/SSS/PBCH·CSI-RS RE 없음
    - CRS 오버헤드는 실제 포트 수, TM에 맞는 전송 방식(예: TM3 → 개루프 CDD), \(\rho_A\) 기준 전력
    - 레이트 매칭 결과 코딩률이 CQI 표의 코딩률에 가장 가깝게

    그래서 실제 PDSCH 조건(CFI 1, 빈 PBCH 서브프레임 등)이 기준과 다르면 기지국이 MCS 매핑에서 보정해야 합니다.

    **CQI → MCS 매핑.** CQI 효율 × (실제 PDSCH RE / 기준 RE)로 목표 효율을 구하고, OLLA 보정을 더한 뒤 MCS를 고르는 방식이 흔합니다. → [스케줄링](../procedures/scheduling.md)

    **RI와 CQI의 의존.** CQI는 보고한 RI와 PMI를 가정해서 계산됩니다. RI가 바뀌면 같은 채널에서도 CQI가 크게 바뀝니다(랭크 2의 레이어당 SINR은 랭크 1보다 낮음). 2 코드워드면 CQI를 2개(두 번째는 차분 3비트) 보고합니다.

    **256QAM CQI 표 (Rel-12).** `altCQI-Table-r12`가 설정되면 Table 7.2.3-2를 써서 CQI 12–15가 256QAM(효율 최대 7.4063)을 가리키고, 저효율 단계 일부가 빠집니다.

    **CSI-RS 기반 CSI (TM9/10).** 채널은 NZP CSI-RS로, 간섭은 CRS(TM9) 또는 CSI-IM(TM10)으로 측정합니다. `pmi-RI-Report` 설정이 없으면 PMI/RI 없이 CQI만 보고합니다(TDD 상호성 빔포밍).

    **CRI (Rel-13).** beamformed CSI-RS(Class B)에서 단말이 여러 CSI-RS 자원(빔) 중 가장 좋은 것의 인덱스를 보고합니다 — NR 빔 보고의 원형입니다.
