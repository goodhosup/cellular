# RSRP · RSRQ · SINR

!!! spec "스펙 · 릴리즈"
    측정량 정의: TS 36.214 §5.1 · 보고 범위·매핑: TS 36.133 §9.1 · L3 필터: TS 36.331 §5.5.3.2 · 측정 갭: TS 36.133 §8.1.2.1

    Rel-8 RSRP/RSRQ → Rel-12 RSRQ 확장 범위 → Rel-13 RS-SINR, RSRP 확장 범위(−156 dBm)

!!! basic "한눈에 보기"
    단말은 셀 신호를 세 가지 숫자로 평가합니다.

    | 측정량 | 의미 | 비유 |
    |---|---|---|
    | **RSRP** | 셀의 참조신호(CRS) RE 하나의 평균 전력 | 상대방 목소리 크기 |
    | **RSRQ** | RSRP를 전체 수신 전력(간섭·잡음 포함)으로 나눈 비율 | 시끄러운 곳에서 그 목소리가 차지하는 비중 |
    | **SINR** | 신호 대 간섭+잡음 비 | 알아들을 수 있는 정도 |

    휴대폰 안테나 막대는 대개 RSRP를 기준으로 표시합니다. 하지만 RSRP가 좋아도 간섭이 많으면(RSRQ·SINR 나쁨) 속도가 느립니다.

## 정의 (TS 36.214) { .l2 }

| 측정량 | 정의 | 보고 범위 |
|---|---|---|
| **RSRP** | 측정 대역 안에서 **CRS 포트 0**(선택적으로 포트 1)이 실린 RE들의 전력 선형 평균 [W] | −140 ~ −44 dBm (Rel-13: −156 dBm까지) |
| **E-UTRA RSSI** | CRS 포트 0이 있는 OFDM 심볼에서 측정 대역 \(N\) RB 전체의 총 수신 전력 (서빙·이웃·간섭·잡음 모두) | — (RSRQ 계산용) |
| **RSRQ** | \(N \times RSRP / RSSI\) | −19.5 ~ −3 dB (Rel-12 확장: −34 ~ 2.5 dB) |
| **RS-SINR** (Rel-13) | CRS RE 전력 / 같은 대역의 간섭+잡음 | −23 ~ 40 dB |

## RSRQ를 직관적으로 { .l2 }

간섭이 없을 때 RSRQ는 **셀 부하**에 따라 달라집니다(2포트 CRS 기준, CRS 심볼에서 RB당 활성 RE 수로 계산).

| 상황 | RB당 RSSI | RSRQ |
|---|---|---|
| 빈 셀, 1포트 CRS | RSRP × 2 | **−3 dB** |
| 빈 셀, 2포트 CRS | RSRP × 4 | −6 dB |
| 100% 부하 (모든 RE 사용) | RSRP × 12 | **−10.8 dB** |
| 100% 부하 + 같은 세기 이웃 셀 1개 | RSRP × 24 | −13.8 dB |

그래서 RSRQ는 "부하+간섭 지표"이고, RSRP와 함께 봐야 합니다.

## 현장에서 쓰는 대략적 기준 { .l2 }

| 품질 | RSRP | RSRQ | SINR |
|---|---|---|---|
| 매우 좋음 | > −80 dBm | > −10 dB | > 20 dB |
| 좋음 | −80 ~ −90 | −10 ~ −15 | 13 ~ 20 |
| 보통 | −90 ~ −100 | −15 ~ −20 | 0 ~ 13 |
| 셀 가장자리 | < −100 (접속 한계 약 −120 ~ −124) | < −20 | < 0 |

사업자·장비·대역마다 다르므로 절대 기준이 아니라 경험적인 참고값입니다.

??? expert "전문가 노트 — 측정 대역, 필터, 갭"
    **측정 대역.** RRC `allowedMeasBandwidth`(6–100 RB)로 단말이 측정에 써도 되는 대역을 제한합니다. 이웃 셀이 좁은 대역이면 그에 맞춥니다. 대역을 넓게 쓰면 측정 정확도가 높아집니다.

    **RSSI 측정 심볼.** Rel-8은 CRS 포트 0이 있는 심볼(0, 4, 7, 11)에서만 RSSI를 잽니다. 이 심볼들의 부하는 실제 PDSCH 부하와 다를 수 있습니다(예: 심볼 0은 제어 영역).
    Rel-10 eICIC에서 측정 서브프레임 제한(`measSubframePattern`)이 설정되면 지정된 서브프레임의 **모든 OFDM 심볼**에서 RSSI를 재도록 바뀌었고, 이후 릴리즈에서 모든 심볼 기반 RSSI·광대역 RSRQ 옵션이 추가되었습니다.

    **L3 필터.** 물리계층 측정(L1, 수십~200 ms 단위 평균)을 RRC가 다시 평균합니다.

    \[
    F_n = (1-a)F_{n-1} + a\,M_n, \qquad a = 1/2^{(k/4)}
    \]

    \(k\) = `filterCoefficientRSRP` (기본 fc4 → a = 0.5). 값이 크면 느리게 반응(안정적), 작으면 빠르게 반응(고속 이동).

    **측정 정확도 (TS 36.133).** 동일 주파수 RSRP 절대 정확도 ±6 dB(정상 조건), 상대 정확도 ±3 dB 수준. 보고 매핑은 1 dB 단위(RSRP_00 = −140 dBm 미만 … RSRP_97 = −44 dBm 이상).

    **측정 갭.** 수신기가 하나인 단말이 다른 주파수를 재려면 서빙 셀 수신을 잠시 멈춰야 합니다.

    | 패턴 | 주기 | 갭 길이 |
    |---|---|---|
    | gp0 | 40 ms | 6 ms |
    | gp1 | 80 ms | 6 ms |

    6 ms = PSS/SSS(5 ms 주기)를 반드시 한 번 포함할 수 있는 길이 + RF 전환 시간. 갭 동안은 스케줄링이 불가능하므로 처리량이 줄어듭니다. CA 단말은 갭 없이 다른 주파수를 잴 수 있는지를 capability로 보고합니다.

## LTE ↔ NR 비교

| 항목 | LTE | NR |
|---|---|---|
| 측정 기준 신호 | CRS | SSB (SS-RSRP), CSI-RS (CSI-RSRP) |
| 빔 | 셀 단위 | **빔별 측정 → 셀 품질 도출** (상위 N개 빔 평균) |
| 측정 시점 | 항상 (CRS 상시) | **SMTC** 창 안에서만 (SSB 주기) |
