# Sidelink와 NR V2X

!!! spec "스펙 · 릴리즈"
    물리계층: TS 38.211 §8, TS 38.212 §8 (SCI), TS 38.213 §16, TS 38.214 §8 · MAC/RRC: TS 38.321 §5.22, TS 38.331 (`SL-ConfigDedicatedNR`) · 구조: TS 23.287 (V2X), TS 23.304 (ProSe) · 요구사항: TS 22.186
    Rel-16 NR V2X → Rel-17 사이드링크 향상(전력 절약, 단말 간 조정), **UE-to-Network 릴레이** → Rel-18 SL-U·SL CA·SL 측위·LTE/NR 공존 → Rel-19 이후 릴레이 확장

!!! basic "한눈에 보기"
    **사이드링크**는 단말끼리 기지국을 거치지 않고 **직접** 통신하는 링크(PC5)입니다.

    LTE V2X는 "주변에 방송"만 했다면, NR V2X는 **특정 차량과 1:1(유니캐스트), 그룹과(그룹캐스트)** 통신하고 **재전송 피드백**까지 지원합니다. 그래서 다음 같은 고급 서비스가 가능합니다.

    - **군집 주행**: 트럭들이 짧은 간격으로 줄지어 달림
    - **센서 공유**: 앞차의 카메라·라이다 데이터를 뒤차가 받음
    - **원격 운전**, **협력 경로 계획**

    Rel-17부터는 사이드링크로 **릴레이**(망 밖 단말을 다른 단말이 중계)도 지원해 공공 안전·커버리지 확장에 씁니다.

## 자원 할당 모드 { .l2 }

| 모드 | 자원 선택 | 지시 |
|---|---|---|
| **Mode 1** | 기지국이 스케줄 | DCI **3_0** (동적, 또는 CG Type 1/2) |
| **Mode 2** | 단말이 **센싱 후 자율 선택** | 자원 풀 설정 (RRC / SIB / 사전 설정) |

## 물리 채널 { .l2 }

| 채널 | 역할 |
|---|---|
| **PSCCH** | 1단계 SCI (SCI 1-A): 자원 예약, 우선순위, 2단계 SCI 형식 |
| **PSSCH** | 데이터 + **2단계 SCI** (SCI 2-A/2-B/2-C: 소스·목적지 ID, HARQ 프로세스, 캐스트 유형) |
| **PSFCH** | **HARQ 피드백** (1비트, 시퀀스 기반) |
| PSBCH + S-PSS/S-SSS (S-SSB) | 사이드링크 동기·방송 |

## 캐스트 유형과 HARQ { .l2 }

| 유형 | HARQ 피드백 |
|---|---|
| 브로드캐스트 | 없음 (블라인드 재전송) |
| **그룹캐스트 옵션 1** | **NACK만** — 일정 거리 안에서 못 받은 단말만 NACK (거리 기반) |
| 그룹캐스트 옵션 2 | 멤버마다 ACK/NACK |
| **유니캐스트** | ACK/NACK + SL CSI 보고 |

Mode 1에서는 송신 단말이 받은 SL HARQ 피드백을 PUCCH로 기지국에 다시 보고해 재전송 자원을 받습니다.

??? expert "전문가 노트 — 센싱, 동기, 릴레이"
    **Mode 2 센싱.** 단말은 과거 센싱 창(100 ms 또는 1100 ms)에서 다른 단말의 SCI 예약과 RSRP를 보고, 선택 창 안에서 RSRP 임계값을 넘는 자원을 제외합니다. 남은 후보가 20% 미만이면 임계값을 3 dB씩 올립니다. 비주기 트래픽을 위해 **재평가(re-evaluation)**와 **선점(pre-emption) 확인**이 추가되었습니다.

    **단말 간 조정 (Rel-17 IUC).** 수신 단말이 "이 자원은 피해라 / 이 자원을 써라"를 송신 단말에 알려 숨은 노드 문제와 반이중 충돌을 줄입니다.

    **전력 절약 (Rel-17).** 보행자 단말을 위한 **부분 센싱**(일부 슬롯만 센싱), 사이드링크 **DRX**.

    **동기 우선순위.** GNSS / gNB / SyncRef UE 중 설정에 따라 기준을 고르고, S-SSB로 동기를 전파합니다.

    **UE-to-Network 릴레이 (Rel-17).** 원격 단말(망 밖) ↔ PC5 ↔ 릴레이 단말 ↔ Uu ↔ gNB. L2 릴레이(SRAP 계층, 원격 단말이 gNB와 RRC·PDCP를 직접 가짐)와 L3 릴레이(IP 라우팅) 두 방식. Rel-18에서 UE-to-UE 릴레이와 다중 경로(multi-path) 릴레이가 추가되었고, 이후 릴리즈에서 다중 홉 등으로 확장이 논의되고 있습니다.

    **LTE V2X와의 공존 (Rel-18).** 같은 채널에서 LTE V2X(기본 안전 메시지)와 NR V2X가 자원을 나눠 쓰는 동일 채널 공존을 정의했습니다.
