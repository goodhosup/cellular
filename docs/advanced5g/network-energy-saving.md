# 네트워크 에너지 절감

!!! spec "스펙 · 릴리즈"
    연구: TR 38.864 (Rel-18, 기지국 전력 모델·기법 평가) · 규격: TS 38.213/38.214/38.321/38.331 Rel-18 (셀 DTX/DRX, 공간·전력 적응, SSB-less SCell), Rel-19 (on-demand SSB·SIB1) · 망 측: TS 38.300 §16.x (NES), RAN3 셀 활성화 · 관리: TS 28.310
    Rel-15/16 구현 기반 절감 → Rel-18 **NES 규격** → Rel-19 NES 2단계 → 6G 설계 원칙

!!! basic "한눈에 보기"
    이동통신망 전력의 대부분은 **기지국(RAN)**이 씁니다. 그리고 기지국은 트래픽이 거의 없는 새벽에도 상당한 전력을 씁니다. SSB, 시스템 정보 같은 **항상 보내야 하는 신호**와 꺼지지 않는 하드웨어 때문입니다.

    망 에너지 절감(NES)은 기지국이 **덜 일할 때 확실히 쉬게** 하는 기능입니다.

    - **시간**: 트래픽이 없을 때 송수신을 멈춤 (셀 DTX/DRX)
    - **공간**: 안테나 일부를 끔 (64개 → 32개)
    - **전력**: 송신 전력을 낮춤
    - **주파수**: 캐리어 일부를 꺼 두고, 필요할 때만 켬 (SSB 없는 SCell, on-demand SSB)

    NR은 LTE와 달리 항상 켜진 CRS가 없어서(lean carrier), 이런 절감을 하기에 원래 유리합니다.

## 기지국 전력 모델 (TR 38.864) { .l2 }

| 상태 | 상대 전력 (대략) | 전환 시간 |
|---|---|---|
| 깊은 수면 | 1 | 50 ms 수준 |
| 얕은 수면 | 50 | 6 ms 수준 |
| 마이크로 수면 | 160 | 수 심볼 |
| 하향 송신 (기준 구성, 최대 부하) | 약 1000 (안테나·대역폭 구성에 따라 스케일) | — |

깊게 쉴수록 전력은 크게 줄지만 깨어나는 데 오래 걸립니다. 그래서 **긴 무송신 구간을 만드는 것**이 절감의 핵심입니다.

## Rel-18 기법 { .l2 }

| 기법 | 동작 | 단말 영향 |
|---|---|---|
| **셀 DTX / DRX** | 셀이 주기적 활성/비활성 패턴을 갖고, 비활성 구간에는 PDCCH·PDSCH(DTX)나 UL 수신(DRX)을 하지 않음. 그룹 공통 DCI(2_9)로 동적 활성화 | 연결 상태 단말이 패턴에 맞춰 동작 (C-DRX와 정렬) |
| **SSB 없는 SCell** | 같은 사이트의 다른 밴드 셀 SSB로 동기 → SCell은 SSB 송신 생략 (inter-band CA) | CA 단말만 해당 |
| **공간 도메인 적응** | 활성 안테나 포트 수를 줄이고, 그에 맞는 CSI-RS 하위 설정으로 CSI 보고 | 여러 포트 가설 CSI 보고 |
| **전력 도메인 적응** | PDSCH 전력 오프셋을 바꾸고, 그에 맞는 CSI 보고 | CSI 하위 설정 |
| NES 셀 접근 제한 | NES 기능 단말만 접속 허용(`cellBarredNES`) | 레거시 단말 영향 최소화 |
| 셀 끄기와 이동성 | 조건부 HO에 "셀 꺼짐" 조건, 페이징·재선택 조정 | |

## Rel-19 기법 { .l2 }

| 기법 | 동작 |
|---|---|
| **On-demand SSB (SCell)** | 평소 SSB를 안 보내다가, 단말이 필요하면(활성화 시) 트리거해 SSB 송신 |
| **On-demand SIB1** | Idle 단말이 UL 웨이크업 신호를 보내면 SIB1 전송 — "SIB1을 항상 방송하지 않는 셀" |
| 공통 신호 적응 | SSB·SIB·페이징 주기와 자원을 부하에 따라 조정 |

??? expert "전문가 노트 — 절감 효과와 트레이드오프"
    **효과 평가.** TR 38.864 시뮬레이션에서는 부하가 낮을수록(예: 10–30%) 셀 DTX/DRX와 공간 적응 조합으로 수십 % 절감이 보고되었습니다. 실제 효과는 하드웨어의 수면 상태 지원(무선부 PA 바이어스 차단 속도 등)에 크게 좌우됩니다.

    **지연·성능 대가.** 셀 DTX 비활성 구간에 도착한 패킷은 기다려야 하므로 지연이 늘고, 안테나를 줄이면 커버리지·용량이 줄어듭니다. 그래서 QoS 인지(지연 민감 단말이 있으면 절감 완화), 트래픽 예측(RAN3 AI/ML) 기반 운용이 함께 쓰입니다.

    **6G로의 연결.** 6G 연구에서는 "**기본적으로 꺼져 있고 필요할 때만 켜는**" 공통 신호 설계(SSB·SIB 최소화, 앵커–부스터 셀 구조)가 핵심 원칙으로 논의됩니다. 5G의 하위 호환 제약(레거시 단말이 SSB를 20 ms마다 기대) 때문에 5G-Advanced에서는 부분적으로만 가능했던 것을 6G에서 근본적으로 바꾸려는 것입니다.
