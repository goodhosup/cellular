# 6G 맛보기

!!! spec "범위"
    ITU-R: M.2160 (IMT-2030 프레임워크, 2023-11) · 3GPP: Rel-20 6G Study (2025-06 시작), Rel-21 6G 규격 (예정) · SA1: TR 22.870 (6G 사용 사례·요구사항)

!!! basic "6G란"
    **6G**는 2030년 전후 상용화를 목표로 하는 차세대 이동통신입니다. ITU에서는 **IMT-2030**이라는 이름으로 부릅니다.

    5G까지는 "더 빠르고, 더 짧은 지연, 더 많은 연결"이 목표였습니다. 6G는 여기에 새 역할이 더해집니다.

    - **센싱**: 통신 전파로 주변의 물체·사람·움직임을 감지 (레이더처럼)
    - **AI**: 망 자체가 AI로 설계·운용되고, AI 서비스를 위한 인프라가 됨
    - **어디서나 연결**: 지상망과 위성을 하나로
    - **지속 가능성**: 에너지 효율을 핵심 설계 목표로

    현재(2026년)는 **3GPP가 6G 기술을 연구하는 단계**입니다. 이 섹션은 확정된 규격이 아니라 공개된 비전과 연구 방향을 정리한 "맛보기"입니다.

## 세대별 비교 (전망 포함) { .l2 }

| 항목 | 4G | 5G | 6G (목표·논의) |
|---|---|---|---|
| ITU 이름 | IMT-Advanced | IMT-2020 | **IMT-2030** |
| 3GPP 첫 규격 | Rel-8 (2008) | Rel-15 (2018) | **Rel-21 (2028–2029 예정)** |
| 주요 대역 | < 3 GHz | FR1 + FR2 (mmWave) | FR1 + **FR3 (7–24 GHz)** + FR2, 장기적으로 sub-THz |
| 최고 속도 | ~1 Gbps | 20 Gbps (목표) | 50–200 Gbps (IMT-2030 연구 범위) |
| 지연 | ~10 ms | 1 ms | 0.1–1 ms |
| 새 개념 | All-IP, OFDMA | 슬라이싱, 빔, SBA | **센싱, AI-native, 지상·위성 통합** |

!!! warning "전망에 대해"
    6G 수치와 기술은 연구 단계의 목표·후보입니다. 실제 규격은 2027년 이후 3GPP 작업 항목에서 정해집니다.
